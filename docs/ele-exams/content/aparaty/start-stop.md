# Dwa niezależne przyciski START i STOP

## Zasada działania

START chwilowo zamyka NO. STOP chwilowo otwiera NC. Dwa operatory są niezależne; puszczenie START nie powoduje samo naciśnięcia STOP.

## Jak czytać rysunek

Na symbolu zespołu rozdziel START i STOP. Oba STOP-y z dwóch miejsc mogą leżeć w szeregu, a START-y równolegle.

## Klasyczne zastosowanie w tych zadaniach

108: START z obu miejsc włącza K1, STOP z dowolnego miejsca przerywa zasilanie cewek. 116: osobne uruchomienie i zatrzymanie.

## Próba, która pomaga zrozumieć

Przeanalizuj osobno każdy klawisz oraz trzymanie drugiego. Sprawdź, czy jest styk podtrzymania.

## Typowa pomyłka

Zastąpienie zespołu jednym operatorem przełączającym jednocześnie NO i NC.
