# Powiązanie ćwiczeń z nauką ELE.02/ELE.05

Źródło przejrzane 2026-10-03: [CKE, informator technik elektryk, Formuła 2019](https://bip.cke.gov.pl/attachments/download/8539), 50 stron. Str. 9–17 dotyczą wybranych zadań ELE.02, str. 30–37 ELE.05; str. 48–49 obejmują metody pomiarów, dokumentowanie oraz lokalizację i naprawę uszkodzeń. Materiał pobrano do przeglądu, nie skopiowano zadań ani ilustracji. Poniższe przyporządkowanie jest autorskim zakresem treningu, nie oficjalną punktacją.

| Scenariusz | Ćwiczona umiejętność | Odniesienie |
|---|---|---|
| Lampa i łącznik | Obwód i napięcie | ELE.02.2; ELE.02.3 |
| Łączniki schodowe | Sterowanie z dwóch miejsc | ELE.02.3 |
| Krzyżowy | Śledzenie połączeń | ELE.02.3 |
| Gniazdo i PE | Tory robocze/ochronne | ELE.02.3 |
| Rozdzielnica | Rozdział i pomiary | ELE.02.3; ELE.05.3 |
| Bistabilny | Sterowanie chwilowe | ELE.02.3 |
| Schodowy | Sterowanie czasem | ELE.02.3 |
| START/STOP | Podtrzymanie cewki | ELE.02.4 |
| DC | Zasilanie sterowania | ELE.02.2/4 |
| Czasówka | Logika A–D | ELE.02.4 |
| Trzy fazy | Kolejność, termik | ELE.02.4; ELE.05.4 |
| Diagnoza | Dowód i retest | ELE.05.3 |

Każde ćwiczenie otwiera wzorzec do badania i modyfikowania. Obecna ocena obejmuje funkcję obwodu na kopii, ciągłość wszystkich PE, zgodność zadeklarowanych barw i aktualny dowód pomiarowy. Diagnoza dodatkowo wymaga hipotezy, naprawy i pomiaru PE przed/po. Scenariusze nie sprawdzają całej listy efektów kształcenia, kompletnej procedury BHP, wszystkich symboli ani normatywnego doboru zabezpieczeń. Ocena 4/4 nie oznacza zaliczenia kwalifikacji.
