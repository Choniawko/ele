# Start dla Codexa

1. Pracuj w repozytorium aplikacji.
2. Przekaż Codexowi `PROMPT_CODEX_Symulator_Elektryczny.md`, `catalog-research-seed.json` i `SOURCES.md`.
3. Wklej polecenie z początku promptu.
4. Wymagaj działającego przekroju: aparat → zaciski → przewód → solver → pomiar → schemat, następnie rozbudowy według etapów.

Prompt zawiera pełny kontrakt produktu, architekturę, instrukcję budowy katalogu i SVG, silnik, pomiary, usterki, 12 scenariuszy, fundament tutora i kryteria odbioru.

Katalog startowy ma 31 rzeczywistych produktów. Jest materiałem badawczym: zweryfikowano tożsamość i zapisane parametry; pełne modele, geometria zacisków oraz część topologii wymagają dalszego opracowania. Wszystkie rekordy mają `published: false`. Nie oznaczaj tego pliku jako gotowej profesjonalnej biblioteki symulacyjnej.

Pierwsza wersja ma być użyteczną lokalną pracownią. Liczba funkcji i dokładność modeli rośnie etapami, a ograniczenia są jawne. Prompt nie jest dowodem, że aplikacja została już zaimplementowana lub zweryfikowana przez elektryka.
